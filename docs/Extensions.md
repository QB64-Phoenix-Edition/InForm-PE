# Extensions

InForm-PE uses various libraries, all of which are available for developers to include in their InForm-PE projects. These libraries reside in the `InForm/extensions` directory.

* [**QBDS**](./QBDS.md): A collection of generic data structure libraries.
* [**Algo**](./Algo.md): A library of general-purpose algorithms.
* [**Catch**](./Catch.md): A minimalistic test framework library.
* [**FontMgr**](./FontMgr.md): A library for finding and retrieving information about system-installed fonts.
* [**GIFPlay**](./GIFPlay.md): A library providing functionality for playing animated GIF files.
* [**INI-Manager**](./INI-Manager.md): A library providing functionality for reading and writing INI files.
* [**Memory**](./Memory.md): A library providing routines for low-level memory operations.
* [**Pathname**](./Pathname.md): A library providing routines for parsing filenames, handling directory separators, and sanitizing path strings.
* [**Resource**](./Resource.md): A library the provides functions to load binary data that has been encoded into Base64 strings.
